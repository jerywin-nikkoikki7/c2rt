# c2rt — Bloxd.io player website

A responsive personal gaming profile for **c2rt** (Bloxd.io username **nikkoTV**), styled with a blue galaxy / space theme. It includes the supplied avatar and pack preview images, player bio, retired Bloxd tiers, other game tiers, featured packs, stats, achievements, setup, and social placeholders.

## Publish on GitHub Pages
1. Create a public repository on GitHub.
2. Upload **all files and folders** from this project into the repository root. Keep `assets/`, `index.html`, `style.css`, and `script.js` together.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. Your site will be at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Personalize it
- `index.html` contains the bio, tiers, pack descriptions, and section text.
- `style.css` controls the galaxy theme and responsive layout.
- `script.js` handles the mobile menu and copy-username button.
- Replace the social placeholders with your actual public YouTube and Discord URLs when you want to share them.
- Add real download links only when the packs are ready and you have permission to share the files.

The website uses the profile and pack screenshots you supplied. The pack download and social links are intentionally not fabricated.
